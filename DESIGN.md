# dot_curt (.curt format) — Design Notes

> Open file-format spec + reference implementation. No app UI. Visual surface
> is the GitHub Pages spec site (`site/`) and README.

## Rules

- Spec site is a Curtis family surface: if restyled, use the Curtis Records
  Office palette (paper `#F5F5F3`, ink `#1A1A18`, green-700 `#0E7A45` accent —
  see curtis-ai-audit design notes; NEWELL neon is retired in this family).
- Mono: JetBrains Mono / system mono for code blocks.
- Format is deliberately vendor-neutral: no NEWELL green branding on the spec
  site beyond a footer attribution.
