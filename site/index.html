The open, single-file AI conversation format

One file.

Full fidelity.

.curt is a single-file format for AI chat conversations — born in Curtis AI Chat and specified here so any app can read and write it. Images and tool calls ride verbatim; a corrupted file is rejected whole, never half-imported.

The envelope

Four fields. That's the contract.

A .curt file is UTF-8 JSON, tab-indented by convention. The envelope is fixed; the conversation is yours. Unknown fields are data, never code — readers preserve them on round-trip and never fail on them. 

{
	"curt":         "curtis-conversation",   // magic — must match exactly
	"version":     1,                        // format version
	"generator":   "writer-name@version",    // provenance — readers must ignore
	"conversation": { /* id, title, createdAt, updatedAt, messages */ }
}

Why .curt

Built to move conversations between apps.

Export should not be a downgrade. The format carries everything your app knows about a conversation, and validates strictly enough that import can trust what it reads.

01

Full fidelity

Images ride inline as base64 inside content. Tool calls, token counts, and app-specific data travel as unknown fields — preserved verbatim, never mangled.

02

Strict by design

Validation is whole-file. parseCurt returns the conversation or null — there is no half-imported state to recover from.

03

Zero dependencies

The reference implementation is one TypeScript file with no platform APIs. A draft-07 JSON Schema ships alongside for every other language.

04

Stable names

The naming convention derives from immutable fields only — 2025-10-09 my-thread 001.curt survives title edits and re-exports.

Quick start

Two functions and a type guard.

serializeCurt and parseCurt are the whole loop. isCurtMessage and isCurtConversation expose the validation predicates; curtFilename builds the recommended file name; CURT_MAGIC and CURT_VERSION carry the envelope constants. 

import { serializeCurt, parseCurt, curtFilename } from 'curt-format';

const body = serializeCurt(conversation, 'my-app@1.0.0');
const back = parseCurt(body);          // CurtConversation | null — null means invalid
const name = curtFilename(back!);       // "2025-10-09 my-thread 001.curt"

Bulk convention

File names you can sort.

Multiple conversations travel as a zip of .curt files. The Curtis convention keeps them chronological and collision-safe:

2025-10-09 fixture-conversation 001.curt

2025-10-09
createdAt as a UTC date — 1970-01-01 if the timestamp isn't finite.
fixture-conversation
Title slug, lowercased, capped at 50 characters — untitled when nothing remains.
001.curt
The part of id after the last underscore — the last 8 characters of id when there is none.
