Try the format.

Drag a ChatGPT or Claude export onto this page and it files every conversation as a dot curt file — converted, named, previewed, and zipped entirely in your browser. There is no server to upload to; the whole porter is this page.

Drop an export here, or click to choose

conversations.json · claude json · export zip · curt

Several files at once are fine, zips included. ChatGPT conversations are read by walking the mapping tree from its current node, so a regenerated answer stays in its branch and out of your file. Claude exports are read from their chat message lists. Bare .curt files are validated whole: a corrupted file is reported, never half-imported. Files are written by porter-web@0.1.0 through the reference implementation, vendored into this page.

No export file? Paste it in.

Paste the contents of a ChatGPT conversations.json or a Claude export — the same conversion runs on the paste, and nothing is uploaded anywhere. A single .curt body pasted as JSON works too.
