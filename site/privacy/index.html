Curt Conversation Exporter — privacy policy

Nothing collected. Nothing sent.

The Curt Conversation Exporter browser extension collects no data of any kind. There is no analytics, no telemetry, and no network request to any server — ever.

How it works.

All processing is local. When you click Export, the extension reads the DOM of the chat page you are already viewing (chatgpt.com, claude.ai), serializes that conversation to a .curt file, and hands the file to your browser's normal download mechanism. The file lands on your disk. Nothing is uploaded, stored elsewhere, or transmitted.

Accounts, storage, cookies.

The extension has no account system, stores nothing, and sets no cookies. It requests exactly two permissions:

  • 01
    activeTab — read the current chat page at the moment you click Export. Nothing runs on any other tab or site.
  • 02
    downloads — save the generated .curt file via your browser's download flow.

Your exported file.

The exported .curt file is yours. What you do with it — where you keep it, who you share it with — is outside the scope of this policy.
